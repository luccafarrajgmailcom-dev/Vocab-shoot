VOCAB QUEST: TARGET RUN
=======================

A playable browser vocabulary shooter-style quiz for the 10 Week 9 and Week 10 words.

HOW TO PLAY
1. Open index.html in a browser.
2. Press DEPLOY TO ARENA.
3. Read the mission definition and click the matching word target.
4. Correct hits earn 100 XP. Wrong targets cost 10 health.
5. The 10 missions and target choices are shuffled every run.

PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository.
2. Upload index.html (README.txt is optional).
3. Open repository Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and / (root), then Save.
6. Open the published URL after GitHub Pages finishes deploying.

The game is self-contained: no libraries, accounts, or network access needed to play.
